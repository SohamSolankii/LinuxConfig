# Mac Apps & Extensions

A list of apps, utilities, and extensions installed on this machine.

## Window & Menu Bar Management

| App | Description | Link |
|-----|-------------|------|
| **Loop** | macOS window manager — resize and snap windows with keyboard shortcuts or gestures | [GitHub](https://github.com/MrKai77/Loop) |
| **Ice** | Menu bar manager — hide and organize menu bar items | [GitHub](https://github.com/jordanbaird/Ice) |

## Notes

- Secrets (API keys, tokens) are **not** stored in this repo. Replace placeholders in `.zshrc` and `.aicommits` with your actual values.
- Ghostty config lives at `~/.config/ghostty/config`
- aicommits config lives at `~/.aicommits`
